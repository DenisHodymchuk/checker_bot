# 👟 Telegram Bot: Трекер кроків для команди

Повністю **безкоштовний** Telegram-бот для корпоративного челенджу щоденних кроків із автоматичним розпізнаванням скріншотів через Vision AI (Google Gemini), системою пільгових днів, штрафною банкою, рейтингами та нагадуваннями.

Працює як локально (SQLite), так і в хмарі (Railway + Supabase PostgreSQL) у режимі 24/7.

---

## 📌 Правила челенджу

1. 🎯 **Щоденна норма — 10 000 кроків** (можна більше, менше — ні). Місячної цілі немає — важлива щоденна дисципліна!
2. 🛡️ **2 пільгових дні на місяць** для кожного учасника (`1/2`, `2/2`), коли можна пройти менше 10 000 кроків або пропустити день без штрафу.
3. 💸 **З 3-го невиконаного дня** у місяці — **штраф 100 грн** за кожен такий день.
4. 🏦 **Штрафна банка**: усі штрафи накопичуються як борг учасника та оплачуються у спільну банку команди.
5. 🔄 **Щомісяця**: 1-го числа лічильники пільгових днів обнуляються для нового челенджу.

---

## ✨ Можливості бота

1. **📸 Автоматичний аналіз фото (Vision AI):**
   - Учасники надсилають скріншоти будь-яких додатків (Apple Health, Garmin, Mi Fitness, Zepp, Samsung Health, Strava, розумні годинники).
   - ШІ точно визначає число кроків і пропонує підтвердити результат.
   - Можливість ручного вводу: `/steps 10500` або просто число `10500` у приватний чат.

2. **🔔 Персональні та групові нагадування:**
   - Щодня у заданий час (за замовчуванням **20:30**) бот нагадує тим, хто ще не надіслав звіт.

3. **🏆 Щоденні командні підсумки (за замовчуванням 22:00):**
   - Турнірна таблиця (🥇, 🥈, 🥉) із позначками 🎯 (виконано), 🛡️ (використано пільгу) чи 💸 (штраф).
   - Блок **Штрафи за сьогодні** (+100 грн).
   - Блок **Поточні борги учасників**.
   - Блок **Штрафна банка** (загальна зібрана сума).

4. **📋 Статус челенджу (`/status`) та Банка (`/bank`):**
   - Перегляд використання пільгових днів кожним колегою за поточний місяць.
   - Перегляд внесків та балансу штрафної банки.

5. **⚙️ Адміністративні можливості:**
   - `/set @user [число] [дата]` — ручне коригування/встановлення кроків адміном у спірних ситуаціях.
   - `/paid @user [сума]` — внесення платежу в штрафну банку та списання боргу.
   - `/set_group` — прив'язка робочої групи для публікації звітів.
   - `/settings` — зміна часу звітів, нагадувань, щоденної норми.

## ☁️ Підключення Supabase (Хмарна база даних)

Щоб дані не втрачалися під час оновлення та перезапуску бота на Railway:

1. Зареєструйтесь безкоштовно на [supabase.com](https://supabase.com).
2. Натисніть **New Project**, оберіть назву (наприклад, `step-tracker`) та встановіть пароль до бази.
3. У лівому бічному меню відкрийте **SQL Editor** -> натисніть **New Query**.
4. Скопіюйте весь вміст файлу **`supabase_schema.sql`** з цього репозиторію, вставте в редактор і натисніть зелену кнопку **Run**.
5. Перейдіть у **Project Settings** (шестерня) -> **API**.
6. Скопіюйте:
   - **Project URL** -> це `SUPABASE_URL`.
   - **anon / public key** або **service_role key** -> це `SUPABASE_KEY`.
7. Вставте ці значення у ваш файл `.env` або у змінні середовища Railway.

## 🚀 Деплой на Railway (Цілодобова робота 24/7)

1. Завантажте ваш код у репозиторій на [GitHub](https://github.com/).
2. Перейдіть на [railway.app](https://railway.app/) та увійдіть через GitHub.
3. Натисніть **New Project** -> **Deploy from GitHub repo** -> оберіть ваш репозиторій `checker_bot`.
4. У вкладці **Variables** вашого сервісу додайте змінні:
   - `BOT_TOKEN` — токен від @BotFather.
   - `GEMINI_API_KEY` — безкоштовний ключ від [Google AI Studio](https://aistudio.google.com/).
   - `SUPABASE_URL` — URL з Supabase.
   - `SUPABASE_KEY` — ключ з Supabase.
   - `ADMIN_ID` — ваш особистий числовий ID у Telegram (дізнатися у @userinfobot).
   - `TIMEZONE` — `Europe/Kyiv`.
5. Railway автоматично збере і запустить бота за кілька секунд!

## 💻 Локальний запуск на комп'ютері

1. Встановіть Node.js (v20 або v24+).
2. Створіть файл `.env` (скопіюйте з `.env.example`) та заповніть ключі.
3. Встановіть залежності та запустіть:
   ```bash
   npm install
   npm start
   ```
*(Примітка: якщо `SUPABASE_URL` не вказано, бот автоматично використовуватиме локальну базу даних SQLite `bot.db`).*
