# 👟 Telegram Bot: Трекер кроків для команди

Повністю **безкоштовний** Telegram-бот для обліку щоденних кроків колег. Бот автоматично розпізнає кількість кроків зі скріншотів через Vision AI (Google Gemini), веде щоденний рейтинг у робочому чаті та особисто нагадує забудькам надіслати результат.

---

## ✨ Можливості бота

1. **📸 Автоматичний аналіз фото (Vision AI):**
   - Колеги надсилають фото/скріншоти будь-яких додатків (Apple Health, Garmin, Mi Fitness, Samsung Health, Strava, годинники).
   - ШІ точно визначає число кроків і пропонує підтвердити або скоригувати число в один клік.
   - Можливість ручного вводу: `/steps 10500`.

2. **🔔 Персональні нагадування в особисті:**
   - Щодня у заданий час (за замовчуванням **20:30**) бот перевіряє, хто ще не здав звіт.
   - Бот надсилає дружнє особисте повідомлення тим, хто забув скинути результат.

3. **🏆 Щоденні командні звіти в робочу групу:**
   - Щовечора у заданий час (за замовчуванням **22:00**) бот публікує турнірну таблицю (🥇, 🥈, 🥉).
   - Відображає відсоток досягнення цілі (🎯), сумарну кількість кроків команди та список тих, хто пропустив день.

4. **⚙️ Гнучкі налаштування для адміністратора (`/settings`):**
   - Зміна часу нагадувань та підсумкового звіту через зручні кнопки.
   - Зміна денної норми кроків (наприклад, 8 000 або 10 000).
   - Ручний запуск звітів і нагадувань у будь-який момент.

## 🚀 Покрокова інструкція швидкого запуску (2 хвилини)

Для роботи потрібно отримати лише 2 безкоштовні ключі:

### Крок 1. Отримання токена бота в Telegram (Безкоштовно)
1. Відкрийте Telegram і знайдіть офіційного бота [@BotFather](https://t.me/botfather).
2. Натисніть **Start** та надішліть команду `/newbot`.
3. Введіть назву для вашого бота (наприклад: `Челендж Кроків`).
4. Введіть юзернейм (має закінчуватися на `bot`, наприклад: `my_team_steps_bot`).
5. **@BotFather** надішле вам токен вигляду: `782348234:AAFxExampleToken...`.
6. Скопіюйте цей токен.

---

### Крок 2. Отримання ключа Google Gemini Vision (100% Безкоштовно)
1. Перейдіть на сайт: [https://aistudio.google.com/](https://aistudio.google.com/)
2. Увійдіть у свій звичайний акаунт Google (Gmail).
3. Натисніть синю кнопку **"Get API key"** (або "Create API key").
4. Натисніть **"Create API key in new project"**.
5. Скопіюйте згенерований ключ (наприклад: `AIzaSy...`).
*(Це офіційний безкоштовний тариф Google AI Studio — до 1500 запитів на добу, банківська карта не потрібна!)*

---

### Крок 3. Налаштування файлу `.env`
1. Відкрийте файл `.env` у цій папці (через блокнот або будь-який редактор).
2. Вставте ваші скопійовані ключі:
```env
BOT_TOKEN=вставте_сюди_токен_від_BotFather
GEMINI_API_KEY=вставте_сюди_ключ_від_Google_AI_Studio
```
3. Збережіть файл.

---

### Крок 4. Запуск бота
- **Простий спосіб:** просто двічі клікніть на файл **`start_bot.bat`** на робочому столі.
- **Через термінал:** виконайте команду:
  ```bash
  npm start
  ```

---

## 👥 Як підключити робочу групу колег

1. Додайте вашого бота в робочий Telegram-чат як учасника.
2. Надайте йому права адміністратора (щоб він міг писати повідомлення).
3. Напишіть у групі команду:
   ```
   /set_group
   ```
4. Бот відповість, що групу прив'язано! Тепер він автоматично публікуватиме щоденні звіти сюди.

---

## 📱 Основні команди для користувачів

| Команда | Опис |
| :--- | :--- |
| `/start` | Приєднатися до челенджу, вітальне меню |
| `/my_stats` | Переглянути особисті рекорди та історію за тиждень |
| `/leaderboard` | Поточний рейтинг команди за сьогодні |
| `/steps 10500` | Записати кроки за сьогодні вручну |
| `/settings` | Панель налаштувань (для адміністратора) |
| `/help` | Коротка довідка та правила |

## 🛠 Технічні деталі
- **Платформа:** Node.js (v20+ / v24+).
- **Фреймворк:** [grammY](https://grammy.dev/).
- **База даних:** Вбудована SQLite (`bot.db`) — зберігається локально, не потребує налаштування серверів.
- **Планувальник:** `node-cron`.
- **Аналіз зображень:** `@google/genai` (моделі `gemini-2.5-flash` та `gemini-1.5-flash`).
